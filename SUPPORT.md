# Support

## How to get help

| Need | Where |
|------|--------|
| Bug report or feature request | GitHub Issues |
| Usage / design questions | GitHub Discussions (enable when the repo is public) or Issues |
| Security vulnerability | [SECURITY.md](SECURITY.md) — private email only |
| Contributing | [CONTRIBUTING.md](CONTRIBUTING.md) |

## What to expect

This is a community / maintainer-driven open-source MVP. Response times vary. There is no commercial SLA attached to this repository unless you arrange one separately.

For production healthcare workloads, evaluate compliance, security, and operational readiness independently—or use a managed FHIR offering that meets your regulatory needs.
