# FHIR fixtures (Synthea)

Synthetic FHIR R4 NDJSON samples generated by [Synthea](https://github.com/synthetichealth/synthea).

Sourced from the public Aidbox Synthea 100-patient set:

- https://storage.googleapis.com/aidbox-public/synthea/100/Patient.ndjson.gz
- https://storage.googleapis.com/aidbox-public/synthea/100/Organization.ndjson.gz
- https://storage.googleapis.com/aidbox-public/synthea/100/Observation.ndjson.gz

Trimmed to a small subset for e2e `$import` / `$load` tests (not the full population).
